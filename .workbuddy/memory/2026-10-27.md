## 右侧队列抽屉：窗口宽度按「抽屉 + 内容区最小值」撑开

背景：窗口 400 宽 + 抽屉 340 → 内容区 60 → 歌词面板 0 宽 → `SizedBox(width: -24)` 断言。

- 新增不变式：抽屉展开时 **窗口宽度 ≥ 抽屉宽度 + `kMinMainContentWidth`(400)**。
  唯一入口 `minWindowWidthForDrawer(drawerWidth)`，`kDrawerOpenMinWindowSize`
  改为由 `kDefaultRightQueueDrawerWidth + kMinMainContentWidth` 派生（默认 740）。
- `right_queue_drawer_controller.dart`：`ensureWindowFitsDrawer()` 同时
  ①把窗口最小宽度抬到该值（否则用户/OS 还能拖窄回去）②不足就 `setSize` 撑开；
  上限取 `FlutterView.display` 的逻辑宽度，避免窗口超出屏幕。`open()` 调它，
  并据前后宽度差记录 `_expandedDeltaWidth` 供 `close()` 还原。
- 其它入口同步：`main.dart` 启动 WindowOptions（抽屉恢复为展开时按公式给初始宽度）、
  `main_layout.dart` 退出小窗模式、`right_queue_panel.dart` 抽屉宽度拖拽结束 / 双击复位。
- 新增用例 `test/player/right_queue_drawer_controller_test.dart`
  （340→740 / 280→680 / 600→1000，且 `kDrawerOpenMinWindowSize` 必须等于公式值）。
- `kMinComfortableWindowWidth`(920) 已删除，旧「窗口 < 920 就加一个抽屉宽」逻辑被取代。

## iOS 添加根目录后 0 首歌：security-scoped bookmark 全链路失效

现象：iOS 26.5 选目录 → 目录出现在列表 → 扫描 `count=0`。
日志 `run.log:144` `PathAccessException ... File Provider Storage (OS Error: Operation not permitted, errno = 1)`。

根因（三处叠加）：
1. picker 返回的 URL 被 `standardizedFileURL.resolvingSymlinksInPath()` 重建后才
   `startAccessingSecurityScopedResource()` / `bookmarkData()` —— **重建即丢 scope token**，
   start 必返回 false。
2. iOS 上 `bookmarkData(options: [])` 生成的 bookmark 跨启动解析回来不带 scope；
   必须 `.minimalBookmark`。
3. `beginScopedAccess` 吞掉 start 结果恒返回 `true`，Dart 记入 `_activeScopedRootPaths`
   后不再重试 → 「添加成功」+ 0 首。

改动：
- `SecurityScopedFileAccess.swift`：新增 `createBookmarkData`（iOS `.minimalBookmark`，
  失败回落 `[]`）、`retainAccess(for:)`（**start 成功才登记**，失败不缓存所以能重试）、
  `beginScopedAccess(for:)`（返回真实结果）、`probeBookmarkAccess`。
  `acquireAccess(for url:)` / `registerPersistentAccess(for url:)` 一律用**原始 URL**。
- `AudioCorePlugin.swift`：`beginScopedAccess` 用真实结果；picker delegate 里
  `acquireAccess`→`registerPersistentAccess`→`isDirectoryReadable`(opendir) 校验，
  不可读回 `DIRECTORY_ACCESS_DENIED`。
- `file_selector_helper.dart`：新增 `pickDirectoryDetailed()` 返回 `DirectoryPickResult`
  （区分 cancelled / accessDenied），`pickDirectory()` 退化为取其 path。
- `scanner_service.addRootPath`：scope 失败不再直接返回，改为**以 `_isDirectoryReadable`
  为准**（否则 macOS `~/Music` 这种无 scope 但可读的根会被误杀）；
  `existingRoot` 且无歌时 `_restartFullRootScan()`（重新选同一目录是恢复授权的入口）。

不变式：**iOS 上任何来自 picker 的 URL，start / bookmark 之前禁止 `standardizedFileURL`
/ `resolvingSymlinksInPath()`**；scope 状态只能来自 `startAccessingSecurityScopedResource()`
的返回值，不能假设成功。

## 目录页默认缩放档 → 网格大（largeGrid）

用户要求：目录页缩放视图默认落到「网格视图大」（`kFolderZoomTierLargeGrid` = 1.0，第 7 档 / 最大档）。

牵连认知：

  都读 `settings.folderZoomScale`），改默认 = 两边一起变。要给歌单单独默认得先拆记忆域。

- 相关测试（folder_layout_utils_test / folder_zoom_gesture_layer_test）都是显式设值，
  不依赖默认，改动后 20 个用例全绿。
