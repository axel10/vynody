# 2026-10-27

## 右侧队列抽屉：窗口宽度按「抽屉 + 内容区最小值」撑开

背景：窗口 400 宽 + 抽屉 340 → 内容区 60 → 歌词面板 0 宽 → `SizedBox(width: -24)` 断言。

- 新增不变式：抽屉展开时 **窗口宽度 ≥ 抽屉宽度 + `kMinMainContentWidth`(400)**。
  唯一入口 `minWindowWidthForDrawer(drawerWidth)`，`kDrawerOpenMinWindowSize`
  改为由 `kDefaultRightQueueDrawerWidth + kMinMainContentWidth` 派生（默认 740）。
- `right_queue_drawer_controller.dart`：`ensureWindowFitsDrawer()` 同时
  ①把窗口最小宽度抬到该值（否则用户/OS 还能拖窄回去）②不足就 `setSize` 撑开；
  上限取 `FlutterView.display` 的逻辑宽度，避免窗口超出屏幕。`open()` 调它，
  并据前后宽度差记录 `_expandedDeltaWidth` 供 `close()` 还原。
- 其它入口同步：`main.dart` 启动 WindowOptions（抽屉恢复为展开时按公式给初始宽度）、
  `main_layout.dart` 退出小窗模式、`right_queue_panel.dart` 抽屉宽度拖拽结束 / 双击复位。
- 新增用例 `test/player/right_queue_drawer_controller_test.dart`
  （340→740 / 280→680 / 600→1000，且 `kDrawerOpenMinWindowSize` 必须等于公式值）。
- `kMinComfortableWindowWidth`(920) 已删除，旧「窗口 < 920 就加一个抽屉宽」逻辑被取代。
