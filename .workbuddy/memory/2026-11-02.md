## 动态流变背景：流速与暗色层默认值调整

需求：两个动态流变的流速默认值统一 0.4；v2（mesh_flow）暗色层不透明度默认 0；v1（mesh_gradient）默认 0.15。

改动：
- `settings_service.dart`：`defaultPlaybackMeshGradientSpeed` 0.05 → 0.4；`defaultPlaybackMeshBackgroundNormalOpacity` 0.15 → 0.0；新增 `defaultPlaybackMeshGradientNormalOpacity = 0.15` + key `playback_mesh_gradient_normal_opacity` + `_playbackMeshGradientNormalOpacityProperty` + 读写器 + `resetVisualizerAppearance()` 复位。
- `playback_page.dart` `_buildBackgroundScrim`：不再共用 `playbackMeshBackgroundNormalOpacity`，按 `backgroundType`（1=v1 / 4=v2）取各自的不透明度；autoDarkLayer 分支仍以「0 视作未设置 → 0.30 基准」的旧语义兜底。
- `visualizer_options_dialog.dart`：暗色层不透明度滑杆跟流速滑杆一样按类型读写（`isMeshGradientBackground` 分流）。
- `test/player/theme_color_helper_test.dart`：断言同步为 v2 = 0.0 / v1 = 0.15 / 两档流速均 0.4。

未做：旧用户已持久化的 `playback_mesh_background_normal_opacity`（曾同时服务 v1/v2）不做迁移，v1 现在读新 key，等于回到新的 0.15 默认。

注意：v1 与 v2 的 `speed` 语义不同（同数值 v1 观感快约 8 倍），统一成 0.4 后 v1 明显更快——这是产品要求的字面结果，若要观感对齐需回到差异化默认。

## 返回图标统一为一笔画折角（kAppBackIcon）

动机：媒体库顶栏返回键用 `Icons.arrow_back_rounded`（带横杆箭头），与详情页圆钮的
iOS 折角（`arrow_back_ios_new_rounded`）两套观感并存。用户希望换成「一笔画成的简单左箭头」。

落地：

- 新增 `lib/utils/app_icons.dart`：`const IconData kAppBackIcon = Icons.chevron_left_rounded;`
- 改用位置：`app_top_nav_bar.dart`（竖屏顶栏 + 胶囊）、`nav_capsule_island.dart`（默认图标）、
  `folder_nav_bar_scaffold.dart`（面包屑返回 + 胶囊）、`app_circular_back_button.dart`（默认图标）、
  `remote_library_page.dart`（3 处 AppBar leading）、`remote_control_page.dart`、
  `remote_library_toolbar_widgets.dart`、`floating_cover_flow_toolbar.dart`、`settings_page.dart`（3 处）。
- 尺寸补偿：折角字形宽度约为带杆箭头的 40%，同字号会明显偏小偏轻，故按原值抬一档——
  导航栏/胶囊/面包屑 20 → 22、圆钮 18 → 20、工具栏 18 → 20，AppBar leading 仍 24。
- `FolderBreadcrumbItem` 新增 `iconSize` 参数（默认 20），只有返回按钮传 22，首页图标保持 20。
- 测试同步：`album_detail_page_test`、`artist_detail_page_test`、`library_page_state_lifecycle_test`
  的 `find.byIcon(Icons.arrow_back_rounded)` 改为 `find.byIcon(kAppBackIcon)`。

验证：`flutter analyze lib` 无 error（135 issues 均为存量 info/warning）；上述三个测试文件 9 项全过。
