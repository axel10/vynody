## 播放页 GPU 排查 → 新增「减少动效」设置组

**背景结论**：实测停在播放页时 3D 引擎约 11.4%（GPU Engine RawValue 差分）。被遮挡层确实在白烧：底层 dock 的 `MiniSpectrumBackground`（60Hz / 80 柱）与 12 处 `PlayingEqualizerIcon`（每实例订阅 60Hz FFT）。但两点判断要记住：
- **FFT 换成自驱动循环动画不省 GPU** —— 渲染侧链路完全相同（60fps 标脏 → CustomPaint → raster/composite），只换数据源是 CPU 侧微调；只有停帧才省。
- 这些图标都包了 `RepaintBoundary`、面积 16×16dp，本身不是 11.4% 大头；大头更像播放页全屏 `BackdropFilter`（`playback_page.dart:1475`）。别对用户承诺大幅提速。

**用户拍板的方案（已落地）**：设置里独立一组「减少动效」，只放两个 bool 开关，不设总开关/预设（总开关无行为且会产生「开但子项都动」的矛盾）；静止态用语义图标（播放中 pause / 暂停 play，仅指示状态不挂点击）；非 Apple 默认关两项动画，Apple 默认开。

**改动文件**：
- `settings_service.dart`：两个 key / SettingProperty / getter+setter / `resetMotionEffects()`；平台默认值唯一来源 `_defaultAmbientMotionEnabled`。
- `settings_section.dart`（motion 枚举 + title/icon/group → core）、新建 `sections/motion_section.dart`、`settings_page.dart`（import + switch）、`settings_search_registry.dart`（2 条）。
- 9 个 `app_*.arb` 各加 7 条文案（CRLF 保留、逐个 JSON 校验），已跑 `flutter gen-l10n`。
- `playing_equalizer_icon.dart`：`_animationEnabled` + `_syncAnimation()`，关闭时 cancel 订阅 + 停兜底 Ticker，`ref.listen(select)` 响应设置变化。
- `floating_dock_bottom_bar.dart`：`_buildMorphingHeader` 按开关决定是否构建 `MiniSpectrumBackground`；播放页 `MiniPlayerCard` 那份不受控。
- `test/pages/settings_page_test.dart`：枚举数量 13→14 + motion 可见断言。

**验证**：`flutter analyze lib` 0 error（141 条既有 info/warning）；改动测试文件 `flutter analyze` No issues。`flutter test` 被 `build/native_assets/windows/native_assets.json` 全仓缺失挡住（既有构建产物问题，与本次改动无关），需重新构建 native assets，未擅自 `flutter clean`。GPU A/B 未做：运行实例仍是旧代码，需重新编译运行。

**边界（已修正）**：初版只在 dock 调用点包了 `if`，用户反馈关掉开关后迷你播放器仍有频谱 —— `MiniSpectrumBackground` 有 **两个** 调用点（dock `floating_dock_bottom_bar.dart:450` 与播放页 `playback/mini_player_card.dart:168`），后者漏了。已把开关判断收敛到 `MiniSpectrumBackground.build` 内部（唯一入口），两个实例一起生效，dock 恢复无条件构建；关闭时 `_stopSubscription()` 真的 cancel。**教训：给共享 widget 加开关，禁止只在某一个调用点包 if**。修复后 `flutter analyze lib` 仍 0 error。
