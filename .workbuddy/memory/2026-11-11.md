## 修复：胶囊「更多」是横向椭圆而不是正圆

现象：媒体库竖屏滚动后右侧「更多」是 45.6×44 的扁胶囊，左侧返回也轻微偏扁。

根因两层：
1. 我把页头口径的 `LibraryToolbarMetrics.buttonSize`(40) 直接塞进了胶囊，
   40 + 两端内边距 8 = 48 > 44，撑开成横排。目录页能保持正圆只是因为它里面是
   32 的紧凑按钮（32 + 8 = 40 < 44，被 `minWidth: 44` 补成正圆）。
2. 更隐蔽：`BoxDecoration.border` 会通过 `decoration.padding` 算进 Container 内边距
   （`AppBlur.glassBorder` 宽 0.8 → 左右共 1.6）。所以实际是 36+8+1.6 = 45.6×44。
   一旦给外层锁 `width: 44`，内层可用宽变 42.4，返回键 44 的 SizedBox 就溢出 1.6。

改法（`lib/widgets/nav_capsule_island.dart`）：
- 新增 `kNavCapsuleSingleActionSize`（= 高 − 8 = 36），媒体库胶囊按钮改用它。
- `NavActionsCapsule` 单动作分支：`tightFor(44,44)`、横向 padding 归零、内容居中；
  多动作仍走 4 + 横排。
- `NavCapsuleIsland` 只有返回键时锁 `width: kNavCapsuleHeight`。
- **描边一律改 `foregroundDecoration`**（只画不占位），两处都改。
- 测试断言左右两枚 `getRect().size` 相等且宽 == `kNavCapsuleHeight`。

## 抽出「滚动过顶判定 + 胶囊显隐」两个公共组件

背景：胶囊外观已共用，但「什么时候浮出」这段业务逻辑在四处各写一遍。

新增：
- `lib/widgets/scroll_past_top.dart` → `ScrollPastTopScope`：`NotificationListener` +
  按 `tabIndex` 分账 + `enabled` 关断，阈值唯一 `kHeaderFloatingCapsuleThreshold`。
  替换 `library_page` / `remote_library_sub_host_page` / `remote_page_shell` /
  `detail_page_shell` 四处（`library_page` 与 `detail_page_shell` 原本写死 36.0，
  常量注释里就点名过 `library_page`，加常量时漏改）。
- `lib/widgets/floating_capsule_header.dart` → `FloatingCapsuleHeader`：
  `AnimatedSlide + AnimatedOpacity + IgnorePointer` 收成一处，`visible` 由调用方算，
  定位留给调用方 `Positioned`（各页 left/height 不同）。

顺手清掉的空转：
- 媒体库宿主的 `AutoHideHeaderScope(enabled: false)` 让 `isHeaderVisible` 恒真，
  里面那层 `AutoHideHeader` 等于白套两层动画 → 整层删除，改由
  `FloatingCapsuleHeader` 承担。`remote_page_shell` / `detail_page_shell` 保留
  （它们的 `navBarBuilder` 签名还要吃 `isHeaderVisible`），但过顶判定已换组件。

测试：新增 `test/widgets/scroll_past_top_test.dart` 6 条（阈值、覆盖阈值、横向滚动、
`enabled=false` 不重建、tab 分账、显隐与点击穿透）。`library_page_state_lifecycle_test`
的 `hostBarOpacity()` 从 `AnimatedOpacity.at(1)` 改成 `.first`（少了一层空转）。
`library_multiselect_test` 仍是既有 2 条失败，与本次无关。
