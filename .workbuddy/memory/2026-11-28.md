# 2026-11-28

## FLIP 转场：点击专辑条目瞬间「闪一下」

**现象**：媒体库首页点专辑卡进详情，动画最开始的一帧被点的那张封面会空一下。

**根因**：`pushAlbumDetailPage` / `pushArtistDetailPage` 在 `Navigator.push` **之前**就
`origin.setSourceHidden(true)`，而新推入的路由首帧被 `MaterialApp` 的 `HeroController`
按 `to.offstage = to.animation.value == 0` 置为 offstage —— 这一帧详情页只在树上、不绘制。
于是出现「源封面已隐藏 + 目标页还没画」的一帧空白（实测 `FRAME0 detailPainted=false
sourceOpacity=0.0`）。`CoverFlipDetailHost` 原本就是对的（量到槽位后才隐藏），
两个手写的 push 函数偏离了这个口径。

**修复**：删掉两处 push 前的 `setSourceHidden(true)`，隐藏统一由详情页/宿主量到目标
槽位后（结束帧回调，下一帧生效）与飞行层同时发生。修后实测
`FRAME0 sourceOpacity=null`（仍可见）→ `FRAME1 detailPainted=true sourceOpacity=0.0`。

**回归**：`test/widgets/album_cover_flip_test.dart` 新增「push 首帧不留空白」，
逐帧断言不变量 `sourceHidden && !detailPainted` 永假；原第一条测试的 frame 0 期望
从「源已隐藏」改成「源仍可见 + 详情页 offstage」。

## 顺带收敛：`CoverFlipSource` 包装层常驻

原来 `if (!hidden) return child!; / Opacity(0, child)` 按状态切根类型，`setSourceHidden`
一次就把整棵子树重建（实测 hide、show 两次都是 `sameElement=false`），`SongThumbnail`
丢 State。本地封面因为有 `thumbnailPath` 走快速路径 + `ImageCache` 命中，暂时看不出来
（实测重建后 op=1.0 不空白）；但远程代表曲的 URL、会话内刚生成还没落库的缩略图只存在
State 里，一旦 ImageCache 被逐出或走慢路径，返回列表就会「空白 + 280ms 淡入」。

**改法**：`build` 恒定返回 `Opacity(opacity: hidden ? 0.0 : 1.0)`，alpha=255 时
`RenderOpacity` 直接绘制子节点、不建图层，视觉与性能均无变化。

**回归**：`album_cover_flip_test.dart` 新增「隐藏/恢复只改 alpha，不重建封面子树」，
断言 `SongThumbnail` 的 Element 在 hide/show 前后 `same()`；断言里凡是「没有 Opacity
包裹层」的写法统一改成「最近那层 opacity == 1.0」（`_sourceCoverOpacity()` helper）；
`artist_avatar_flip_test.dart` 同步改 frame 0 / pop 的两处期望。
